# Sleep-Disorder-Prediction-ML
A Flask-based Machine Learning application for predicting sleep disorders using supervised learning models with data preprocessing, visualization, and performance evaluation.
# Project Overview
Sleep disorders significantly affect human health and quality of life. Early identification can support timely intervention and improve overall well-being. This project presents a machine learning-based system for predicting sleep disorders using demographic, lifestyle, and physiological attributes.
# Motivation
While studying machine learning, I wanted to understand how different classification algorithms perform on healthcare datasets. Inspired by an IEEE research paper, I implemented the proposed workflow, experimented with alternative machine learning models, and compared their performance to identify a more accurate solution.
# Objectives
- Build an ML prediction system.
- Compare classification algorithms.
- Improve prediction accuracy.
- Develop an interactive Flask interface.
# Methodology
- Data Cleaning

- Model Training
- Performance Evaluation
- Prediction

# Results
The proposed implementation achieved approximately 96% classification accuracy, demonstrating improved predictive performance over the baseline approach explored during the literature review.
